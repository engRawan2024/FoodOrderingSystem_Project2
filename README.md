## Files (in `src/`)
- `FoodOrderingSystem.java` : main class with the menu loop
- `Payable.java`, `OrderOperations.java` : interfaces
- `MenuItem.java` (abstract), `MainCourse.java`, `Beverage.java`, `Dessert.java` : food classes
- `Customer.java` (abstract), `StudentCustomer.java`, `RegularCustomer.java` : customer classes
- `OrderLine.java`, `Order.java`, `OrderManager.java` : orders

## Run
- Eclipse: import the files from `src/` into a Java project and run `FoodOrderingSystem`.
- Jar: `java -jar FoodOrderingSystem.jar`
